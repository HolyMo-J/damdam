# 용어집

문서 전체에서 같은 말을 같은 뜻으로 쓰기 위한 표준 용어 모음이다 (2026-10-02, 용어 감사 결과). 용어가 헷갈리거나 새 용어를 쓰려 할 때 읽는다.

- 표기: "(일반)"은 이 프로젝트 문서가 아니라 일반적으로 쓰이는 뜻이다. 근거가 문서나 코드에 있으면 출처를 적었다. 확인하지 못한 것은 "확인 못 함"이라고 적었다.
- 코드 식별자(클래스명, 프로필명, 열 이름)는 바꾸지 않는다. 예를 들어 `papertrading` 패키지와 `paper-probe` 프로필의 "paper"는 코드 이름이고, 문서 본문에서는 "가상매매"라고 쓴다.
- 이력 문서(done.md, troubleshooting.md)는 날짜가 붙은 과거 기록이라 옛 용어를 그대로 두고, 오류만 정정 주석으로 고친다.

## 매매와 가격

| 용어 | 뜻 | 출처 |
| --- | --- | --- |
| 진입, 진입가 | 진입은 포지션을 새로 여는 매수 체결(가상매매 포함)이고 진입가는 그 체결 가격이다. 1단계의 기준 가격은 평단가다 | 이 문서 |
| 청산 | 포지션을 정리하는 일 전체 (익절, 손절, 시간 청산) | 이 문서 |
| 매도 | 청산을 위한 주문 행위 | 이 문서 |
| 자동 매도 | 봇이 직접 낸 매도 주문. 지금은 시간 청산뿐이다. OCO의 익절과 손절은 토스 서버가 발동하므로 봇이 낸 주문이 아니다 | README |
| 시간 청산 | 최대 보유 5거래일에 도달하면 파는 청산. 청산 규칙 v0의 물림 방지 장치 | strategy.md |
| 익절, 손절 | 진입가 + ATR 1배(익절)와 진입가 - ATR 1배(손절)에 닿으면 정리하는 청산 (청산 규칙 v0) | strategy.md |
| 감시가 (트리거) | 조건주문이 발동하는 기준 가격. 가격이 감시가에 도달하면 조건이 발동되어 주문이 만들어진다 | 토스 명세 |
| 주문가 | 발동한 뒤 내는 지정가 주문의 가격. 예: 손절 감시가 9,900에 주문가 9,899 (가상매매 가정) | `PaperLedgerTest` |
| OCO | One-Cancels-the-Other. 두 조건(익절과 손절)을 동시에 감시하다 하나가 충족되면 나머지는 자동 취소되는 조건주문. 국내 주식은 KRX 정규장에서만 발동한다 | 토스 명세 |
| ATR | 평균 하루 변동폭 (Average True Range, 일반). 이 프로젝트는 최근 14거래일 ATR을 쓴다. "ATR 1배"는 익절과 손절의 폭이다 | strategy.md |
| 1R | 손절폭. ATR 1배를 매수가로 나눈 값 | strategy.md |
| 슬리피지 | 기대한 가격보다 불리하게 체결되는 정도를 비율로 가정한 값 (일반). 적용 대상은 아래 표 | strategy.md |
| 1호가 | 매도 1호가(ask1)는 살 때 닿는 가장 낮은 매도 호가, 매수 1호가(bid1)는 팔 때 닿는 가장 높은 매수 호가 (일반) | 일반 |
| VI | 변동성 완화장치. 토스 명세의 "매수 유의사항 조회"에 VI 발동 정보가 포함된다 | 토스 명세 |
| NXT | 한국거래소(KRX) 외의 국내 대체거래소 넥스트레이드의 약칭 (일반). 토스 명세는 약칭만 쓰고 풀이하지 않으며, 일봉 거래량은 KRX와 NXT 통합 기준이라고만 적혀 있다 | 토스 명세 |

슬리피지 적용 대상:

| 맥락 | 값 | 적용 대상 | 근거 |
| --- | --- | --- | --- |
| 2단계 백테스트 탐색 | 0.1% (민감도로 0과 0.2%) | 진입, 손절, 시간 청산 매도 | backtest-log.md |
| 3단계 가상매매 | 0.2% (참고 보고 0, 0.1%, 0.3%) | 진입(시가 x 1.002)과 시간 청산 매도(시가 x 0.998). 익절은 지정가, 손절은 주문가 그대로라 더하지 않는다. 실측한 값이 아니다 | strategy.md |

## 이 용어집이 아직 못 정한 것

- 1단계 "보유 시작일 기준 영업일"과 가상매매 "봉 개수"는 휴장일이 낀 구간에서 하루 어긋날 수 있다. 실측 비교는 안 했다.
- 신호 확정 시각은 20:20, 20:22, 20:30 등 문서마다 다르게 적혀 있고, 구현 (3)에서 하나로 정하고 근거를 한 곳에 둔다.
- 토스에 모의 계좌가 있는지는 확인 못 함이다. 이 문서는 "모의 계좌"라는 말을 쓰지 않는다.
