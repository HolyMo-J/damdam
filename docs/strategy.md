# 전략 문서

## 1단계: 조회와 청산 봇

### 작업 순서
1. 조회 전용 스크립트: 토큰 발급과 재사용, 보유 종목과 평가손익 출력. 토스 앱 화면과 대조해 검증
2. 청산 기준 도달 시 알림
3. 사용자 허락 후, 체결 감지 시 조건주문으로 자동 청산

### 청산 규칙 v0 (검증 전 출발점)
- 손절의 역할은 평소 흔들림을 버티고 큰 손실 사고만 막는 것. 1% 같은 좁은 고정 손절은 쓰지 않는다
- 이유: 한국 개별주는 단기 반전 근거가 더 많아 좁은 손절은 반등 직전에 털리기 쉽고, 손절 매도에도 세금 0.20%가 붙음
- 기준값: 최근 14거래일 ATR (평균 하루 변동폭)
- 익절: 체결가 + ATR 1배
- 손절: 체결가 - ATR 1배
- 시간 청산: 최대 보유 5거래일 도달 시 매도. 물림 방지의 주력 장치
- 수량: 손절 시 손실 금액이 1회 손실 한도를 넘지 않도록 매수 수량 결정. 한도 금액은 사용자가 정한다
- 1대1 비율과 ATR 1배는 단순함 때문에 고른 값이며 최적이라는 근거는 없음

### 대안 규칙 비교 기록
- 실제 청산은 v0 규칙으로 하되, 같은 거래에 대해 대안 규칙이었다면 어떤 결과였을지 함께 기록한다
- 대안: 사용자 기존 습관 (1% 익절, 손절 없음), ATR 0.5배, ATR 1.5배
- 거래가 충분히 쌓이면 규칙별 비용 반영 손익을 비교해 v1 규칙을 정한다

### 안전 장치
- 매도가 막히는 상황: 하한가, VI 발동, 거래정지 시 매도 실패를 감지하고 알린다
- 자동 정지: 하루 손실 한도, 연속 손실 횟수 초과 시 봇 정지
- 수동 정지: `bot/data/STOP` 파일이 있으면 자동 매도와 OCO 등록/수정을 즉시 중단하고 알림. 이미 등록된 OCO는 토스 서버에서 계속 동작하므로 이 정지는 서버의 익절/손절을 막지 못한다 (취소는 앱이나 WTS에서 직접)
- 주문 금액 한도(현재 10만원, 폭주 방지용): 시간 청산 자동 매도는 예상 주문 금액이 이 한도를 넘으면 매번 건너뛰고 알림만 보낸다. 포지션 금액을 한도 안으로 줄이기 전까지는 계속 건너뛰어지므로, 실전 전환 1단계에서는 매수 금액 자체를 이 한도 안으로 맞춘다

### 구현 시 주의
- 조건주문 OCO는 종목당 1개만 가능. 같은 종목을 추가 매수하면 새로 등록하지 말고 기존 조건주문을 수정
- 조건주문은 PC가 꺼져도 동작하지만, 시간 청산은 봇이 실행 중이어야 동작함. 봇 정지 시 알림 필요
- 체결 감지는 실시간 주문 이벤트 웹소켓 사용. 연결이 끊긴 동안의 이벤트는 재전송되지 않으므로 재연결 후 주문 목록으로 재동기화

## 2단계: 과열 급락 반등 전략 백테스트
- 아래 전략 초안을 과거 데이터로 검증
- 매도 세금 0.20%와 매매 수수료 반영. 현재 수수료율은 API로 확인
- 기간을 앞뒤로 나눠 앞에서 찾은 설정이 뒤 기간에서도 통하는지 확인
- 생존 편향 주의: 상장폐지 종목이 데이터에 포함되는지 확인
- 코스피200 보유 수익률과 비교 (실제 매수가 아니라 데이터 비교)
- 발표된 연구의 효과는 이후 크게 줄어드는 경향이 있으므로 결과를 보수적으로 해석

### 백테스트 탐색 방법론 (2026-09-20 확정)
- 탐색 파라미터: 하락폭 기준, 거래량 배수 기준, 목표 반등폭(익절), 손절폭(변동성 기준). 최대 보유일수는 5거래일로 고정하고 탐색 대상에서 제외한다
- 탐색 방법: 좌표 하강 방식. 나머지 파라미터는 고정한 채 하나씩 최적 구간을 찾고, 값을 고정한 뒤 다음 파라미터로 넘어간다. 필요하면 한 바퀴 더 반복한다. 전체 시도 횟수 상한은 200회. 탐색에 실제로 쓴 파라미터 순서는 시도 기록 CSV에 남긴다 (순서가 결과에 영향을 줄 수 있어서 재현과 사후 점검을 위해)
- 기간 3분할 (시간순, 종목별로 자기 데이터 기간 안에서 나눔): 탐색 구간(가장 오래된 약 50%, 숫자를 찾는 용도) / 확인 구간(중간 약 30%, 탐색에서 찾은 숫자를 그대로만 적용하고 재조정하지 않음) / 최종 검증 구간(최근 약 20%, 탐색과 확인이 모두 끝난 뒤 딱 한 번만 열어 실전 전환 기준으로 판정하고, 그 전까지 코드에서 아예 로드하지 않는 방식으로 봉인). 정확한 비율은 아래 데이터 볼륨 확인 결과를 반영해 조정할 수 있다
  - 사용 데이터는 2015-06-15 이후로 제한한다 (2026-09-21 결정). 이 날 가격제한폭이 ±15%에서 ±30%로 넓어졌고 그 전에는 토요일 장도 있어서 시장 구조가 지금과 다르다. `analysis/backtest/periods.py`의 `BACKTEST_START`로 읽을 때 자르며 원본 CSV는 그대로 둔다. 처음에 수집기 상한(1만 봉)까지 받아 1988년 데이터가 섞였고, 그대로 3분할하면 탐색 구간 대부분이 2000년대 이전이 되는 문제가 있어 바로잡았다
  - 자르고 나면 30종목 중 24종목이 같은 달력 구간(탐색 2015-06~2021-01, 확인 2021-01~2024-06, 최종 2024-06~2026-09)을 갖는다. 나머지는 상장이 늦은 종목이라 구간이 짧고 달력 시기가 조금씩 다르다 (최종 구간이 가장 짧은 종목은 약 227봉). 종목 간 시장 상황이 다른 시기가 일부 섞이는 점은 결과 해석 시 감안한다
- 데이터 볼륨 확인 결과 (2026-09-20, `analysis/data`의 실제 캔들로 확인, 아래 수치는 1988년부터 전체 기간 기준이라 2015-06-15 이후로 자르면 다시 계산해야 한다): 30종목의 데이터 기간이 최대 34배 차이(1988년부터인 종목과 2021~2022년 상장 종목 혼재). 참고용 임계값(최근 3거래일 하락률, 20일 평균 대비 거래량 배수)으로 신호 빈도를 가늠해본 결과, 느슨한 조합(하락폭 -8%, 거래량 1.5배)은 확인/최종 구간에 각각 수백 건이 잡히지만, 엄격한 조합(하락폭 -15%, 거래량 3배)은 최종 구간에 20여 건뿐이라 100건 기준을 채우기 어렵다. 신호가 드물수록 반등 효과가 더 뚜렷하게 나오는 경향과 충돌할 수 있음
- 거래 건수 기준 적용: 위 판단 기준의 "앞뒤로 나눈 기간마다 각각 100건 이상"은 확인 구간과 최종 검증 구간 두 곳에 각각 적용한다. 탐색 구간은 숫자를 찾는 용도라 이 기준에서 제외한다. 데이터 볼륨 문제에 대응해, 좌표 하강으로 숫자를 찾을 때 기대 수익뿐 아니라 확인/최종 구간에서 이 100건 기준을 채울 수 있는 예상 거래 빈도인지도 탐색 목표에 포함한다. 수익성이 좋아 보여도 확인/최종 구간 표본을 채울 수 없을 만큼 드문 조합은 애초에 후보에서 제외한다
- 확인 구간 실패 시 절차: 확인 구간에서 기대값 부호가 바뀌거나 판단 기준에 못 미치면, 탐색 구간 결과의 차선책 1개로 딱 한 번만 재시도한다 (200회 한도 안에 포함). 그래도 안 되면 전략을 재검토한다. 재시도 여부와 무관하게 확인 구간 성과 수치는 통과/탈락을 거르는 용도로만 쓰고, 실제 성과 추정치는 오직 최종 검증 구간 결과만 신뢰한다 (재시도 자체가 확인 구간 수치에 낙관 편향을 남기기 때문)
- 종목군 분할: 탐색 구간에서만 30종목을 15/15로 나눠 교차 확인한다. 표본이 작아 판정 기준으로는 쓰지 않고 참고용으로만 본다
- 룩어헤드 차단: 신호는 당일 종가 확정 후 판단한다. 진입 체결가는 다음 거래일 시가로 고정한다 (호가 데이터가 없어 docs/records.md의 "매도 1호가" 원칙 대신 시가로 근사하며, 이 근사는 결과 해석 시 감안한다). ATR, 거래량 평균 등 지표는 신호일 이전 데이터로만 계산한다
- 동일 날짜 손절/익절 순서 불확실성: 일봉 데이터만으로는 하루 안에 손절가와 익절가가 둘 다 닿았을 때 실제로 어느 것이 먼저 체결됐는지 알 수 없다. 보수적으로 손절이 먼저 닿았다고 가정하고, 이런 날이 전체 거래의 몇 퍼센트인지 별도로 기록해 결과 해석 시 불확실성으로 감안한다
- 시도 횟수 기록: 파라미터 조합, 결과(수익률, 낙폭, 거래 건수), 시도 순번을 CSV로 남긴다. 최종 보고에는 "N번 시도 중 이 조합을 선택했다"를 명시한다

## 3단계: 가상매매
- 실제 주문 없이 실시간 시세로 규칙대로 가상 매매하고 기록
- 기록 방식과 가상 체결 규칙은 docs/records.md 참고
- 자동 정지 장치를 실전과 동일하게 적용
- 대형주 그룹과 중형주 그룹을 나눠 기록해 반등 효과 차이를 확인

## 4단계: 소액 실전
- 가상매매 시작 전에 정해둔 실전 전환 기준을 충족할 때만 진행

## 나중에 검토
- 미국 주식: 한국 연구 근거를 그대로 적용하지 않고 별도 전략으로 설계. 해외 주식은 양도소득세 구조가 다름
- AI 판단 추가: 규칙 기반이 안정된 뒤 검토

## 전략 초안: 과열 급락 반등 스윙 (검증 전 가설)

### 규칙
- 대상: 거래량이 충분한 대형주, 중형주. 복권형 소형주 제외
- 진입: 최근 며칠 하락폭이 크고 거래량이 평소보다 크게 늘어난 종목. 시장 전체 급락일은 진입 금지
- 진입 전 제외: 정리매매, 투자경고, 투자위험 등 매수 유의 종목
- 가짜 급락 제외: 권리락, 배당락, 액면분할로 인한 가격 변화. 토스 API의 수정주가(adjusted=true)를 쓰면 액면분할과 감자는 이미 연속적으로 이어진다 (2026-09-21 삼성전자 등 30종목 확인). 그래도 조정 반영이 어긋났을 가능성에 대비해, `원본 종가 / 수정 종가` 비율이 하루 사이 0.5% 넘게 바뀐 날(`analysis/backtest/detect_events.py`, 2015-06-15 이후 30종목에서 38건)이 최근 20거래일 안에 있는 신호는 백테스트에서 제외한다. 한계: 토스가 조정하지 않은 사건(예: 유상증자 권리락 급락)은 이 비율에 잡히지 않아 가격 데이터만으로는 걸러낼 수 없다. 수정주가 기준 하루 -20% 이하 급락이 30종목에서 15건 있었고 모두 거래량이 평소의 1.5배 이상이었다. 진입 조건에 하락폭이 크게 들어가는 전략이라 이런 사건이 섞일 수 있음을 결과 해석 시 감안한다
- 청산은 먼저 오는 것: 목표 반등폭 도달, 최대 보유 5거래일 도달, 변동성 기준의 넓은 손절
- 금지: 급등주 추격, 물타기, 동시 보유 종목 수 초과, 1회 투자금 한도 초과
- 하락폭, 거래량 배수, 목표 반등폭, 손절폭 등 숫자는 백테스트로 정한다. 근거 없이 정하지 않는다
- 거래 시간: 처음에는 정규장만

### 근거 요약
- 한국 시장은 직전 월 수익률의 단기 반전이 유의하고 단기 모멘텀은 확인되지 않았다는 연구가 있음
- 회전율 높은 종목군에서 과거 하락 종목의 반등이 확인됨
- 개인 군집매수 이후 수익률 반전이 관찰됨
- 거래 빈도가 높고 복권형 주식을 선호하는 개인 투자자일수록 성과가 저조
- 가격이 무작위로 움직이면 손절 규칙은 기대수익을 낮추고, 모멘텀이 있을 때만 가치를 더한다는 연구가 있음
- 과거 한국 자료에서 장중 수익률은 0 또는 음수, 장 마감부터 다음 시가까지는 양수였음 (2010년 이전 자료)

### 한계
- 근거 연구는 월 단위, 포트폴리오 단위 결과이고 이 전략은 며칠 단위 개별 종목 적용이라 간격이 있음
- 보유 종목 수가 적으면 결과가 운에 크게 흔들림
- 대형주에서는 반전 효과가 약할 수 있음
- 생존 편향: 백테스트 종목군이 "오늘 기준" 거래대금 상위 30종목이라, 지금까지 살아남아 잘된 종목만 골라 과거를 검증하는 셈이다. 과거에 상위였다가 하락하거나 상장폐지된 종목이 빠져 있어 반등 효과가 실제보다 좋게 나올 수 있다. API에서 이를 바로잡을 방법이 없다 (아래 확인 완료 참고)
- 사용자의 초단타 성향과 맞지 않아 규칙을 손으로 뒤집고 싶어질 수 있음
- 현실적인 기대치는 비용 반영 후 코스피200 보유와 비슷하거나 못 미치는 수준. 확실한 가치는 청산 규율과 데이터 기반 판단 습관

## 판단 기준 (가상매매 시작 전에 확정)
- 실전 전환 기준 (2026-09-19에 백테스트 결과를 보기 전에 확정. 결과를 본 뒤에는 바꾸지 않는다)
  - 최소 거래 건수: 백테스트 200건 이상, 앞뒤로 나눈 기간마다 각각 100건 이상. 가상매매는 최소 50건, 목표 100건. 근거: 30건은 통계 판단의 최소선, 50~100건은 의미 있는 판단, 실전 전 100건 이상, 기관은 200~500건이라는 통용 기준 (블로그와 교육 자료 수준이라 학술 근거는 아님). 상관 높은 거래 여러 건보다 독립적인 거래가 낫다
  - 비용 반영 기대값: 거래당 평균 순수익이 왕복 비용의 2배 이상 (국내 왕복 비용은 수수료 0.015% x 2 + 매도세 0.20% = 약 0.23%이므로 약 0.46% 이상). 함께 손절폭(1R) 대비 기대값도 0보다 커야 한다. 생존 편향과 오차를 감안해 여유를 둔 기준
  - 최대 손실폭 한도: 백테스트 최대 낙폭 10% 이하 (본인이 규칙을 뒤집고 싶어질 낙폭을 20%로 보고 그 절반). 함께 Calmar 비율(연수익률 / 최대 낙폭) 1.0 이상. 실전 낙폭은 보통 백테스트보다 크게 나온다
  - 코스피200 대비 성과: 비교 대상은 두 가지이고 모두 실제 매수 없이 데이터로만 비교한다. (1) 코스피200 보유 (시장 기회비용) (2) 같은 30종목 동일가중 보유 (종목 선정 편향 제거). 두 기준 각각에 대해 아래를 모두 만족해야 합격 (안정 우선 기준)
    - 비용 반영 수익률이 기준과 같거나 높으면 통과
    - 수익률이 기준보다 낮으면, 최대 낙폭이 기준의 절반 이하이고 Calmar 비율이 기준보다 높아야 인정
    - 어느 경우든 위의 거래 건수, 기대값, 낙폭 한도(10%와 Calmar 1.0 이상) 조건은 별도로 모두 충족해야 한다. 그래서 낙폭만 작고 벌지 못하는 전략은 통과하지 못한다
    - 이유: 이 봇의 1차 목적은 수익 극대화가 아니라 청산 규율(낙폭 관리)이고, 현실적 기대치가 지수와 비슷하거나 못 미치는 수준이라 지수를 무조건 넘어야 하는 기준은 대부분의 전략을 탈락시켜 결과를 본 뒤 기준을 낮추고 싶어질 위험이 있다. 목적이 바뀌면(예: 주수입 규모로 확대) 낙폭 한도와 최소 거래 건수를 더 엄격하게 잡은 새 버전의 기준을 정한다
- 전략 중단 기준: 위 기준에 명확히 못 미치거나 일정 기간 이상 손실이 이어지는 경우 (구체적 기간은 미정)
- 결과를 본 뒤 기준을 바꾸지 않는다

## 전략 수정 규칙
- 기록이 충분히 쌓이기 전에는 규칙을 바꾸지 않는다
- 수정은 버전 단위로 묶어서 하고, 수정한 규칙은 백테스트로 다시 검증한다

## 확인 필요
- 해외(US) 매매 수수료율의 적용 종료일이 2026-09-19로 임박함 (`GET /api/v1/commissions` 실제 조회 결과). 프로모션 요율일 가능성이 있어서, 그 이후 요율이 바뀌면 다시 조회해서 백테스트 비용 가정을 갱신해야 함

## 확인 완료
- 토스 API 캔들 데이터의 과거 제공 범위: 삼성전자(005930)로 실제 테스트해보니 안전 상한(50페이지, 1만 봉)에 걸릴 때까지도 1988년 데이터가 나옴. 백테스트에 필요한 기간(최근 10~20년)은 전혀 문제없이 확보 가능
- 권리락, 배당락, 액면분할을 API로 걸러낼 수 있는지: 이벤트 목록을 따로 주는 API는 없음. 대신 토스 FAQ에 "액면분할·유상증자·배당락 등 기업행위가 발생하면 수정주가 기능으로 조정된 값이 보일 수 있다"고 명시돼 있어서, 캔들을 `adjusted=true`/`adjusted=false` 둘 다 받아 같은 날짜 가격을 비교하는 방식으로 감지 가능 (두 값이 갈리는 날 = 기업행위가 있었던 날). 2단계 백테스트 코드에서 이 비교 로직을 구현해서 쓴다
- 과거 시점 기준으로 종목을 고를 수 있는 데이터가 API에 있는지: 없음. `GET /api/v1/rankings`는 날짜를 지정할 수 없고 "지금 기준 최근 기간"만 준다. 상장폐지 종목은 공식 FAQ상 과거 시세 조회가 404라서 데이터 자체가 없다 (`GET /api/v1/stocks/all`은 `status=DELISTED` 필터가 있어 목록은 얻을 수 있지만 시세를 받을 수 없음). 가능한 완화책은 캔들의 가격 x 거래량으로 과거 시점의 거래대금 순위를 재구성하는 것뿐이며, 이것으로도 상장폐지 종목의 부재는 해소되지 않는다. 결과를 해석할 때 이 편향을 감안한다
- 캔들 제공 범위 문서와 실제의 차이: 공식 FAQ는 국내 2022-11-23 이후만 제공된다고 하지만, 실제 삼성전자 조회에서는 1988년 데이터가 나옴. 실제 응답을 기준으로 삼되, 종목별로 다를 수 있으니 수집 시 첫 봉 날짜를 확인한다
- 현재 매매 수수료율: `GET /api/v1/commissions`로 실제 계좌 조회 결과, 국내(KR) 0.00015(0.015%, 2021-01-01부터 사실상 무기한), 해외(US) 0.001(0.1%, 종료일 2026-09-19). 매도 세금 0.20%(국내)와 별개로 이 수수료도 백테스트 비용 계산에 반영
