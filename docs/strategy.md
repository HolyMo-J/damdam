# 전략 문서

## 1단계: 조회와 청산 봇

### 작업 순서
1. 조회 전용 스크립트: 토큰 발급과 재사용, 보유 종목과 평가손익 출력. 토스 앱 화면과 대조해 검증
2. 청산 기준 도달 시 알림
3. 사용자 허락 후, 체결 감지 시 조건주문으로 자동 청산

### 청산 규칙 v0 (검증 전 출발점)
- 손절의 역할은 평소 흔들림을 버티고 큰 손실 사고만 막는 것. 1% 같은 좁은 고정 손절은 쓰지 않는다
- 이유: 한국 개별주는 단기 반전 근거가 더 많아 좁은 손절은 반등 직전에 털리기 쉽고, 손절 매도에도 세금 0.20%가 붙음
- 기준값: 최근 14거래일 ATR (평균 하루 변동폭)
- 익절: 체결가 + ATR 1배
- 손절: 체결가 - ATR 1배
- 시간 청산: 최대 보유 5거래일 도달 시 매도. 물림 방지의 주력 장치
- 수량: 손절 시 손실 금액이 1회 손실 한도를 넘지 않도록 매수 수량 결정. 한도 금액은 사용자가 정한다
- 1대1 비율과 ATR 1배는 단순함 때문에 고른 값이며 최적이라는 근거는 없음

### 대안 규칙 비교 기록
- 실제 청산은 v0 규칙으로 하되, 같은 거래에 대해 대안 규칙이었다면 어떤 결과였을지 함께 기록한다
- 대안: 사용자 기존 습관 (1% 익절, 손절 없음), ATR 0.5배, ATR 1.5배
- 거래가 충분히 쌓이면 규칙별 비용 반영 손익을 비교해 v1 규칙을 정한다

### 안전 장치
- 매도가 막히는 상황: 하한가, VI 발동, 거래정지 시 매도 실패를 감지하고 알린다
- 자동 정지: 하루 손실 한도, 연속 손실 횟수 초과 시 봇 정지
- 수동 정지: `bot/data/STOP` 파일이 있으면 자동 매도와 OCO 등록/수정을 즉시 중단하고 알림. 이미 등록된 OCO는 토스 서버에서 계속 동작하므로 이 정지는 서버의 익절/손절을 막지 못한다 (취소는 앱이나 WTS에서 직접)
- 주문 금액 한도(현재 10만원, 폭주 방지용): 시간 청산 자동 매도는 예상 주문 금액이 이 한도를 넘으면 매번 건너뛰고 알림만 보낸다. 포지션 금액을 한도 안으로 줄이기 전까지는 계속 건너뛰어지므로, 실전 전환 1단계에서는 매수 금액 자체를 이 한도 안으로 맞춘다

### 구현 시 주의
- 조건주문 OCO는 종목당 1개만 가능. 같은 종목을 추가 매수하면 새로 등록하지 말고 기존 조건주문을 수정
- 조건주문은 PC가 꺼져도 동작하지만, 시간 청산은 봇이 실행 중이어야 동작함. 봇 정지 시 알림 필요
- 체결 감지는 실시간 주문 이벤트 웹소켓 사용. 연결이 끊긴 동안의 이벤트는 재전송되지 않으므로 재연결 후 주문 목록으로 재동기화

## 2단계: 과열 급락 반등 전략 백테스트
- 아래 전략 초안을 과거 데이터로 검증
- 매도 세금 0.20%와 매매 수수료 반영. 현재 수수료율은 API로 확인
- 기간을 앞뒤로 나눠 앞에서 찾은 설정이 뒤 기간에서도 통하는지 확인
- 생존 편향 주의: 상장폐지 종목이 데이터에 포함되는지 확인
- 코스피200 보유 수익률과 비교 (실제 매수가 아니라 데이터 비교)
- 발표된 연구의 효과는 이후 크게 줄어드는 경향이 있으므로 결과를 보수적으로 해석

### 백테스트 탐색 방법론 (2026-09-20 확정)
- 탐색 파라미터: 하락폭 기준, 거래량 배수 기준, 목표 반등폭(익절), 손절폭(변동성 기준). 최대 보유일수는 5거래일로 고정하고 탐색 대상에서 제외한다
- 탐색 방법: 좌표 하강 방식. 나머지 파라미터는 고정한 채 하나씩 최적 구간을 찾고, 값을 고정한 뒤 다음 파라미터로 넘어간다. 필요하면 한 바퀴 더 반복한다. 전체 시도 횟수 상한은 200회. 탐색에 실제로 쓴 파라미터 순서는 시도 기록 CSV에 남긴다 (순서가 결과에 영향을 줄 수 있어서 재현과 사후 점검을 위해)
- 기간 3분할 (시간순, 30종목 공통 달력 경계로 나눔. 2026-09-21에 종목별 비율에서 바꿈: 상장이 늦은 종목의 탐색 구간이 다른 종목의 확인/최종 구간과 달력상 겹쳐 봉인이 새기 때문): 탐색 구간(가장 오래된 약 50%, 숫자를 찾는 용도) / 확인 구간(중간 약 30%, 탐색에서 찾은 숫자를 그대로만 적용하고 재조정하지 않음) / 최종 검증 구간(최근 약 20%, 탐색과 확인이 모두 끝난 뒤 딱 한 번만 열어 실전 전환 기준으로 판정하고, 그 전까지 코드에서 아예 로드하지 않는 방식으로 봉인). 정확한 비율은 아래 데이터 볼륨 확인 결과를 반영해 조정할 수 있다
  - 사용 데이터는 2015-06-15 이후로 제한한다 (2026-09-21 결정). 이 날 가격제한폭이 ±15%에서 ±30%로 넓어졌고 그 전에는 토요일 장도 있어서 시장 구조가 지금과 다르다. `analysis/backtest/periods.py`의 `BACKTEST_START`로 읽을 때 자르며 원본 CSV는 그대로 둔다. 처음에 수집기 상한(1만 봉)까지 받아 1988년 데이터가 섞였고, 그대로 3분할하면 탐색 구간 대부분이 2000년대 이전이 되는 문제가 있어 바로잡았다
  - 경계는 확인 구간 시작 2021-01-28, 최종 구간 시작 2024-06-13이다 (`periods.py`의 `CONFIRM_START`, `FINAL_START`). 2,767봉을 가진 24종목의 50/30/20% 경계와 같은 값이다. 상장이 늦은 6종목은 앞 구간이 짧거나 비어도 같은 날짜를 쓴다. 엔진의 로더(`load_search_data`)는 최종 구간 행을 호출자에게 돌려주지 않는다 (파일은 통째로 읽히지만 즉시 버림)
- 데이터 볼륨 (2026-09-21 재측정): 2015-06-15 이후로 자르면 24종목이 2,767봉이고 나머지 6종목은 1,136~2,691봉이다 (최대 약 2.4배 차이). 이전에 적었던 "최대 34배 차이"와 "엄격한 조합은 최종 구간 20여 건"은 1988년부터 받은 데이터 기준이거나 근거를 찾지 못한 수치라 삭제했다
- 신호 빈도 실측 (2026-09-21, `analysis/backtest/report_frequency.py`, 탐색 구간 34,798 종목-일, 청산은 익절 3%와 손절 ATR 1.5배로 고정, 동시 보유 5종목): 탐색 구간 건수를 봉 수 비율(확인 0.60, 최종 0.40)로 환산한 추정치가 각각 150건(100건 기준 x 여유 1.5) 이상인 조합은 격자 20개 중 (하락폭 -6%, 거래량 1.5배) 하나뿐이다. 원인은 동시 보유 상한이 아니라 신호 자체가 드문 것이다: (-8%, 2배)는 신호 221건이 겹침 제거로 204건, 상한 5 적용으로 183건이 된다. 신호는 시장 급락일에 몰린다 (2020-03-13 하루에 20종목). 판단 기준의 100건은 확정 사항이라 낮추지 않고, 탐색 격자 쪽을 조정한다
- 거래 건수 기준 적용: 위 판단 기준의 "앞뒤로 나눈 기간마다 각각 100건 이상"은 확인 구간과 최종 검증 구간 두 곳에 각각 적용한다. 탐색 구간은 숫자를 찾는 용도라 이 기준에서 제외한다. 데이터 볼륨 문제에 대응해, 좌표 하강으로 숫자를 찾을 때 기대 수익뿐 아니라 확인/최종 구간에서 이 100건 기준을 채울 수 있는 예상 거래 빈도인지도 탐색 목표에 포함한다. 수익성이 좋아 보여도 확인/최종 구간 표본을 채울 수 없을 만큼 드문 조합은 애초에 후보에서 제외한다
- 확인 구간 실패 시 절차: 확인 구간에서 기대값 부호가 바뀌거나 판단 기준에 못 미치면, 탐색 구간 결과의 차선책 1개로 딱 한 번만 재시도한다 (200회 한도 안에 포함). 그래도 안 되면 전략을 재검토한다. 재시도 여부와 무관하게 확인 구간 성과 수치는 통과/탈락을 거르는 용도로만 쓰고, 실제 성과 추정치는 오직 최종 검증 구간 결과만 신뢰한다 (재시도 자체가 확인 구간 수치에 낙관 편향을 남기기 때문)
- 종목군 분할: 탐색 구간에서만 30종목을 15/15로 나눠 교차 확인한다. 표본이 작아 판정 기준으로는 쓰지 않고 참고용으로만 본다
- 룩어헤드 차단: 신호는 당일 종가 확정 후 판단한다. 진입 체결가는 다음 거래일 시가로 고정한다 (호가 데이터가 없어 docs/records.md의 "매도 1호가" 원칙 대신 시가로 근사하며, 이 근사는 결과 해석 시 감안한다). ATR, 거래량 평균 등 지표는 신호일 이전 데이터로만 계산한다
- 동일 날짜 손절/익절 순서 불확실성: 일봉 데이터만으로는 하루 안에 손절가와 익절가가 둘 다 닿았을 때 실제로 어느 것이 먼저 체결됐는지 알 수 없다. 보수적으로 손절이 먼저 닿았다고 가정하고, 이런 날이 전체 거래의 몇 퍼센트인지 별도로 기록해 결과 해석 시 불확실성으로 감안한다
- 시도 횟수 기록: 파라미터 조합, 결과(수익률, 낙폭, 거래 건수), 시도 순번을 CSV로 남긴다. 최종 보고에는 "N번 시도 중 이 조합을 선택했다"를 명시한다
- 엔진 규칙 (2026-09-21, `analysis/backtest/engine.py`, 독립 검토 반영. 단위 테스트 15개는 `test_engine.py`)
  - 신호: 최근 3거래일 등락률이 하락폭 기준 이하이고, 신호일 거래량이 직전 20거래일 평균(거래량 0인 날 제외)의 배수 기준 이상. 신호일 앞에 20봉이 없거나, 신호일 포함 21봉 안에 거래량 0인 날 또는 조정 이벤트가 있으면 제외한다 (평균, 거래정지, 이벤트 세 윈도우를 같게 맞춤. 신규 상장 초기의 가짜 급락도 이 조건으로 걸러짐)
  - 진입: 다음 거래일 시가. 그날 거래량이 0이거나 고가와 저가가 같으면(가격 고정) 진입하지 않는다. 종목당 한 번에 한 포지션이고 이전 청산일과 같은 날 재진입도 막는다
  - 청산: 진입 봉 자체의 고가와 저가부터 검사한다. 시가가 이미 손절가 이하이거나 익절가를 넘는 갭은 시가에 체결한다. 같은 날 둘 다 닿으면 손절이 먼저다. 익절은 고가가 익절가를 엄격히 넘을 때만 체결로 보고, 고가가 정확히 같은 경우는 비율을 따로 센다. 시간 청산은 진입 봉 + 5번째 봉의 시가이고 그날이 거래정지면 거래가 재개된 첫 봉의 시가에 판다
  - 구간 끝: 진입 봉 + 5가 구간 마지막 봉을 넘는 신호는 경로와 결과에 상관없이 버린다 (일찍 끝난 거래만 남는 편향 방지)
  - 동시 보유 5종목 상한, 초과 시 그날 신호 중 3일 하락폭이 큰 순으로 채운다
  - 비용: 수수료 0.015% 양쪽, 매도세는 청산일(체결일) 기준 연혁표를 쓴다 (`engine.py`의 `SELL_TAX_SCHEDULE`, 증권거래세와 농어촌특별세 합계). 2015-06-15부터 0.30%, 2019-05-30부터 0.25%, 2021-01-01부터 0.23%, 2023-01-01부터 0.20%, 2024-01-01부터 0.18%, 2025-01-01부터 0.15%, 2026-01-01부터 0.20%. 2019-05-30 이후는 코스피와 코스닥 합계가 같아 시장 구분이 필요 없다. 확인한 출처는 금융투자협회, 코스콤 등의 2019년 인하 안내와 2021년 이후를 정리한 두 곳이다. **확인하지 못한 것**: 2015-06-15부터 2019-05-29까지 0.30%가 유지됐다는 점 (2019년 인하 직전이 0.30%라는 것만 확인). 초기 구간의 세율이 지금보다 높아 탐색 구간 성과는 그만큼 보수적으로 나온다. 판단 기준의 "왕복 비용 약 0.23%, 기대값 0.46% 이상"은 확정된 값이라 그대로 두고, 백테스트 수익은 연도별 실제 세율을 반영한 순수익으로 그 기준과 비교한다. 슬리피지는 파라미터로 두고 0 기준과 민감도를 함께 본다
  - 결과와 함께 낼 것: 서로 다른 진입 날짜 수, 신호가 가장 몰린 5일의 비중, 손절 우선 발생 비율, 고가와 익절가가 같은 경계 비율, 같은 자격의 모든 날에 진입하는 대조군의 평균 수익 (신호 조건이 만드는 엣지와 종목군의 상승 드리프트를 구분)
  - 구현하지 않은 것: 시장 전체 급락일 진입 금지 (지수 데이터가 없어 진입 날짜 집중도 보고로 대신 확인), 호가 단위 반올림 (수정주가라 과거 호가 단위와 안 맞음), 포트폴리오 최대 낙폭과 Calmar (다음 작업)

- 탐색 설정 (2026-09-21 고정, 결과를 보기 전): 목적함수는 탐색 구간의 거래당 평균 순수익(비용 반영)이고, 건수 하한은 최종 구간 100건에 여유 계수 1.5를 곱해 탐색 구간 건수로 역산한 375건이다. 격자는 하락폭 3, 4, 5, 6, 8%, 거래량 배수 1.0, 1.5, 2, 3, 익절 1, 2, 3, 4, 5%, 손절 ATR 0.5, 1, 1.5, 2, 3배이고 시작점은 (5%, 1.5배, 3%, 1.5배), 순서는 하락폭, 거래량, 익절, 손절 후 한 바퀴 더다. 처음 고정한 격자(하락폭 6~15%, 거래량 1.5~4배, 시작점 8%와 2배)는 신호 빈도 실측에서 20개 중 1개만 건수 기준을 채워 성과를 보기 전에 위와 같이 바꿨다 (2026-09-21, 사용자 승인). 바뀐 격자는 20개 중 12개가 기준을 채우고, 시작점은 탐색 구간 건수 615건으로 하한(375건)을 채운다. 하락폭이 얕아져 "과열 급락"보다 "가벼운 하락 후 반등"에 가까워진 점은 결과 해석 시 감안한다. 튜닝 중 확인/최종 구간 건수는 탐색 구간 건수에 봉 수 비율(확인 0.60, 최종 0.40)을 곱해 추정하고 두 구간을 직접 세지 않는다. 바꿀 때는 이유와 시점을 시도 기록에 남긴다
- 탐색 실행 규칙 (2026-09-21, 성과 수치를 보기 전에 고정, `damdam-reviewer` 검토 반영)

  - 좌표 하강은 최대 2바퀴이고, 한 바퀴에서 바뀐 좌표가 없으면 그 전에 끝낸다. 각 좌표는 격자 전체를 훑어 건수 하한(탐색 구간 375건)을 채우는 값 중 목적함수 최대를 고른다. 동률(차이 1e-9 이내)이면 현재 값을 유지하고 현재 값이 후보에 없으면 건수가 많은 쪽을 고른다
  - 시도 기록에는 스윕에 참가한 모든 값을 행으로 남기고, 새로 평가한 것인지(`new_evaluation`)와 최초 시도 번호를 함께 적는다. 보고에는 "200번 중"이 아니라 실제 새로 평가한 횟수를 쓴다. 파라미터 기록 외에 엔진 커밋 해시, 격자, 하한, 경계일, 세율표, 슬리피지를 `search_meta.json`에 남긴다
  - 진단 기록 (시도마다): 순수익 표준편차와 표준오차, 상한 적용 전 후보 수와 겹침 제거 후와 상한 후 건수, 청산 사유 비율, 평균 보유 봉 수, 하한 여유(n/375), 하루 최대 진입 수, 연도별 건수, 거래 집합 해시, 2020-02-20~2020-04-30 진입을 뺀 평균과 건수, 대조군 두 가지 (전 종목 모든 날 진입, 신호 거래와 같은 날 진입한 자격 있는 비신호 종목 평균). 상위 5일 비중은 동시 보유 상한 때문에 최대 25/n이라 정보가 없어 쓰지 않는다
  - 차선책: 평가된 조합 중 하한을 채우고, 주 후보와 격자 칸 거리(네 파라미터의 칸 수 차이 합)가 3 이상인 것 중 목적함수 최고 1개. 주 후보와 차선책은 확인 구간을 열기 전에 `analysis/results/candidates.json`에 저장한다
  - 참고 지표(슬리피지 민감도, 종목 15/15 분할, 연도별, 대조군 대비 엣지, 시기 제외 평균)는 보고만 하고 확인 구간에 넘길지를 바꾸지 않는다. 15/15 분할은 뽑힌 조합의 거래를 정렬한 종목 코드의 짝수와 홀수 인덱스로 나눠 계산하며 재실행하지 않는다. 확인 구간 판정은 기대값 부호와 판단 기준만으로 하고, 재시도 사유에는 "확인 구간 100건 미달"도 포함한다 (재시도는 1회뿐)
  - 알고 시작하는 한계: (1) 시작점 표준오차가 0.17%p라 판단 기준 0.46%의 약 2.7배 수준이고, 상관된 후보 수십 개 중 최댓값은 우연만으로 몇 0.1%p 부풀 수 있다 (2) 확인 구간 세율(0.23%, 0.20%)이 탐색 구간(0.30%, 0.25%)보다 낮아 확인 구간 순수익이 세율만으로 0.05~0.1%p 높게 나온다. 기대값 부호가 바뀌는지 볼 때 이만큼 유리하게 기운다 (3) 375건 하한은 봉 수 비례 추정이라 신호가 급락 시기에 몰리는 특성을 반영하지 못한다. 상장이 늦은 6종목 중 4개는 탐색 구간 봉이 없어 탐색은 약 25종목, 확인과 최종은 30종목이다 (4) 익절 경계 비율은 수정주가라 익절가가 호가 단위 값이 아니어서 거의 0일 것이고 의미 있는 진단이 아니다
- 탐색 결과 (2026-09-21, 탐색 구간만 사용, 확인과 최종 구간은 열지 않음, `damdam-reviewer` 검토 반영. 원자료는 `analysis/results/`)
  - 새로 평가한 조합 23개(하한 충족 19개), 2바퀴. 주 후보는 하락폭 4%, 거래량 1.5배, 익절 5%, 손절 ATR 1.5배이고 탐색 구간 거래 680건, 거래당 평균 순수익 +0.234%다 (슬리피지 0.1% 반영). 표준오차는 독립 가정 0.182%, 진입 주 단위 군집 0.221%이므로 t는 약 1.1~1.3이다. 판단 기준 약 0.46%에 못 미치고, 슬리피지 0에서도 +0.365%로 미달이다. 이 값은 "찾아낸 수익"이 아니라 23개 중 최댓값이다: 격자 한 칸 옆 이웃 7개의 평균은 +0.074%이고 하한 충족 19개의 평균은 -0.34%~+0.23%, 중앙값은 약 0이다 (승자의 저주 규모)

  - 동시 보유 상한이 결과의 양수를 만들고 있다: 상한을 풀면 853건에 평균 -0.059%이고, 상한이 걸러낸 189건은 -1.06%다. 급락이 몰린 날의 신호를 버리는 것이 사실상 시장 급락일 필터로 작동한다. 전략 초안의 "시장 전체 급락일 진입 금지"는 지수 데이터가 없어 구현하지 않았는데, 그 규칙의 효과가 상한을 통해 우연히 들어와 있다
  - 청산: 익절 +4.67%(228건), 익절 갭 +5.85%(29건), 손절 -6.05%(127건), 손절 갭 -7.69%(28건), 시간 청산 -0.34%(268건). 중앙값 +1.18% 대비 평균 +0.23%는 왼쪽 꼬리가 아니라 익절과 손절의 이봉 구조 때문이다. 5봉 시가 청산만 하면 539건에 +0.347%로 규칙이 있는 결과보다 높다 (건수가 달라 엄밀한 비교는 아님). 익절 체결은 고가가 익절가를 넘으면 정확히 그 가격에 체결된다는 낙관 가정이 몰려 있다

  - 연도별은 건수 65~155에 표준오차가 0.4~0.5%p라 개별로 유의하지 않다 (2015년 -0.80%, 2018년 +0.60%). 2021년 3건은 보고할 값이 아니다. 종목 15/15 분할은 뽑힌 거래를 나눈 것이라 독립 재현이 아니다. 2020-02-20~04-30을 뺀 평균은 +0.260%로 코로나 시기 덕은 아니다
  - 차선책 (하락폭 4%, 거래량 2배, 익절 3%, 손절 1.5배)은 탐색 평균이 -0.025%라 확인 구간 실패 시 재시도가 사실상 의미 없다. 격자 거리 3 이상이라는 사전 규칙 때문에 더 좋은 근접 조합이 빠졌다

## 전략 초안: 과열 급락 반등 스윙 (검증 전 가설)

### 규칙
- 대상: 거래량이 충분한 대형주, 중형주. 복권형 소형주 제외
- 진입: 최근 며칠 하락폭이 크고 거래량이 평소보다 크게 늘어난 종목. 시장 전체 급락일은 진입 금지
- 진입 전 제외: 정리매매, 투자경고, 투자위험 등 매수 유의 종목
- 가짜 급락 제외: 권리락, 배당락, 액면분할로 인한 가격 변화. 토스 API의 수정주가(adjusted=true)를 쓰면 액면분할과 감자는 이미 연속적으로 이어진다 (2026-09-21 삼성전자 등 30종목 확인). 그래도 조정 반영이 어긋났을 가능성에 대비해, `원본 종가 / 수정 종가` 비율이 하루 사이 0.5% 넘게 바뀐 날(`analysis/backtest/detect_events.py`, 2015-06-15 이후 30종목에서 38건)이 최근 20거래일 안에 있는 신호는 백테스트에서 제외한다. 한계: 토스가 조정하지 않은 사건(예: 유상증자 권리락 급락)은 이 비율에 잡히지 않아 가격 데이터만으로는 걸러낼 수 없다. 수정주가 기준 하루 -20% 이하 급락이 30종목에서 15건 있었고 모두 거래량이 평소의 1.5배 이상이었다. 진입 조건에 하락폭이 크게 들어가는 전략이라 이런 사건이 섞일 수 있음을 결과 해석 시 감안한다
- 청산은 먼저 오는 것: 목표 반등폭 도달, 최대 보유 5거래일 도달, 변동성 기준의 넓은 손절
- 금지: 급등주 추격, 물타기, 동시 보유 종목 수 초과, 1회 투자금 한도 초과
- 하락폭, 거래량 배수, 목표 반등폭, 손절폭 등 숫자는 백테스트로 정한다. 근거 없이 정하지 않는다
- 거래 시간: 처음에는 정규장만

### 근거 요약
- 한국 시장은 직전 월 수익률의 단기 반전이 유의하고 단기 모멘텀은 확인되지 않았다는 연구가 있음
- 회전율 높은 종목군에서 과거 하락 종목의 반등이 확인됨
- 개인 군집매수 이후 수익률 반전이 관찰됨
- 거래 빈도가 높고 복권형 주식을 선호하는 개인 투자자일수록 성과가 저조
- 가격이 무작위로 움직이면 손절 규칙은 기대수익을 낮추고, 모멘텀이 있을 때만 가치를 더한다는 연구가 있음
- 과거 한국 자료에서 장중 수익률은 0 또는 음수, 장 마감부터 다음 시가까지는 양수였음 (2010년 이전 자료)

### 한계
- 근거 연구는 월 단위, 포트폴리오 단위 결과이고 이 전략은 며칠 단위 개별 종목 적용이라 간격이 있음
- 보유 종목 수가 적으면 결과가 운에 크게 흔들림
- 대형주에서는 반전 효과가 약할 수 있음
- 생존 편향: 백테스트 종목군이 "오늘 기준" 거래대금 상위 30종목이라, 지금까지 살아남아 잘된 종목만 골라 과거를 검증하는 셈이다. 과거에 상위였다가 하락하거나 상장폐지된 종목이 빠져 있어 반등 효과가 실제보다 좋게 나올 수 있다. API에서 이를 바로잡을 방법이 없다 (아래 확인 완료 참고)
- 사용자의 초단타 성향과 맞지 않아 규칙을 손으로 뒤집고 싶어질 수 있음
- 현실적인 기대치는 비용 반영 후 코스피200 보유와 비슷하거나 못 미치는 수준. 확실한 가치는 청산 규율과 데이터 기반 판단 습관

## 판단 기준 (가상매매 시작 전에 확정)
- 실전 전환 기준 (2026-09-19에 백테스트 결과를 보기 전에 확정. 결과를 본 뒤에는 바꾸지 않는다)
  - 최소 거래 건수: 백테스트 200건 이상, 앞뒤로 나눈 기간마다 각각 100건 이상. 가상매매는 최소 50건, 목표 100건. 근거: 30건은 통계 판단의 최소선, 50~100건은 의미 있는 판단, 실전 전 100건 이상, 기관은 200~500건이라는 통용 기준 (블로그와 교육 자료 수준이라 학술 근거는 아님). 상관 높은 거래 여러 건보다 독립적인 거래가 낫다
  - 비용 반영 기대값: 거래당 평균 순수익이 왕복 비용의 2배 이상 (국내 왕복 비용은 수수료 0.015% x 2 + 매도세 0.20% = 약 0.23%이므로 약 0.46% 이상). 함께 손절폭(1R) 대비 기대값도 0보다 커야 한다. 생존 편향과 오차를 감안해 여유를 둔 기준
  - 최대 손실폭 한도: 백테스트 최대 낙폭 10% 이하 (본인이 규칙을 뒤집고 싶어질 낙폭을 20%로 보고 그 절반). 함께 Calmar 비율(연수익률 / 최대 낙폭) 1.0 이상. 실전 낙폭은 보통 백테스트보다 크게 나온다
  - 코스피200 대비 성과: 비교 대상은 두 가지이고 모두 실제 매수 없이 데이터로만 비교한다. (1) 코스피200 보유 (시장 기회비용) (2) 같은 30종목 동일가중 보유 (종목 선정 편향 제거). 두 기준 각각에 대해 아래를 모두 만족해야 합격 (안정 우선 기준)
    - 비용 반영 수익률이 기준과 같거나 높으면 통과
    - 수익률이 기준보다 낮으면, 최대 낙폭이 기준의 절반 이하이고 Calmar 비율이 기준보다 높아야 인정
    - 어느 경우든 위의 거래 건수, 기대값, 낙폭 한도(10%와 Calmar 1.0 이상) 조건은 별도로 모두 충족해야 한다. 그래서 낙폭만 작고 벌지 못하는 전략은 통과하지 못한다
    - 이유: 이 봇의 1차 목적은 수익 극대화가 아니라 청산 규율(낙폭 관리)이고, 현실적 기대치가 지수와 비슷하거나 못 미치는 수준이라 지수를 무조건 넘어야 하는 기준은 대부분의 전략을 탈락시켜 결과를 본 뒤 기준을 낮추고 싶어질 위험이 있다. 목적이 바뀌면(예: 주수입 규모로 확대) 낙폭 한도와 최소 거래 건수를 더 엄격하게 잡은 새 버전의 기준을 정한다
- 전략 중단 기준: 위 기준에 명확히 못 미치거나 일정 기간 이상 손실이 이어지는 경우 (구체적 기간은 미정)
- 결과를 본 뒤 기준을 바꾸지 않는다

## 전략 수정 규칙
- 기록이 충분히 쌓이기 전에는 규칙을 바꾸지 않는다
- 수정은 버전 단위로 묶어서 하고, 수정한 규칙은 백테스트로 다시 검증한다

## 확인 필요
- 해외(US) 매매 수수료율의 적용 종료일이 2026-09-19로 임박함 (`GET /api/v1/commissions` 실제 조회 결과). 프로모션 요율일 가능성이 있어서, 그 이후 요율이 바뀌면 다시 조회해서 백테스트 비용 가정을 갱신해야 함

## 확인 완료
- 토스 API 캔들 데이터의 과거 제공 범위: 삼성전자(005930)로 실제 테스트해보니 안전 상한(50페이지, 1만 봉)에 걸릴 때까지도 데이터가 나옴. 2015-06-15 이후만 쓰는 백테스트에는 충분함. 정정 (2026-09-21): 정확히 10,000행인 파일이 9개이고 그중 삼성전자와 기아의 첫 행이 둘 다 1988-03-14라서, 1988년은 히스토리의 시작이 아니라 수집기 상한에 잘린 지점이다. 이 9종목 밖의 종목은 기간 차이가 실제 상장 시점 차이다
- 권리락, 배당락, 액면분할을 API로 걸러낼 수 있는지: 이벤트 목록을 따로 주는 API는 없음. 대신 토스 FAQ에 "액면분할·유상증자·배당락 등 기업행위가 발생하면 수정주가 기능으로 조정된 값이 보일 수 있다"고 명시돼 있어서, 캔들을 `adjusted=true`/`adjusted=false` 둘 다 받아 같은 날짜 가격을 비교하는 방식으로 감지 가능 (두 값이 갈리는 날 = 기업행위가 있었던 날). 2단계 백테스트 코드에서 이 비교 로직을 구현해서 쓴다
- 과거 시점 기준으로 종목을 고를 수 있는 데이터가 API에 있는지: 없음. `GET /api/v1/rankings`는 날짜를 지정할 수 없고 "지금 기준 최근 기간"만 준다. 상장폐지 종목은 공식 FAQ상 과거 시세 조회가 404라서 데이터 자체가 없다 (`GET /api/v1/stocks/all`은 `status=DELISTED` 필터가 있어 목록은 얻을 수 있지만 시세를 받을 수 없음). 가능한 완화책은 캔들의 가격 x 거래량으로 과거 시점의 거래대금 순위를 재구성하는 것뿐이며, 이것으로도 상장폐지 종목의 부재는 해소되지 않는다. 결과를 해석할 때 이 편향을 감안한다. 실측 (2026-09-21): 2015-06-15부터 현재까지 수정 종가 배율의 중앙값이 4.7배이고 30종목 중 29종목이 올랐다 (내린 종목은 0.70배 하나). 급락 후 반등 전략에 구조적으로 유리한 표본이라 백테스트 결과는 상한 추정으로 보고한다
- 캔들 제공 범위 문서와 실제의 차이: 공식 FAQ는 국내 2022-11-23 이후만 제공된다고 하지만, 실제 삼성전자 조회에서는 1988년 데이터가 나옴. 실제 응답을 기준으로 삼되, 종목별로 다를 수 있으니 수집 시 첫 봉 날짜를 확인한다
- 현재 매매 수수료율: `GET /api/v1/commissions`로 실제 계좌 조회 결과, 국내(KR) 0.00015(0.015%, 2021-01-01부터 사실상 무기한), 해외(US) 0.001(0.1%, 종료일 2026-09-19). 매도 세금 0.20%(국내)와 별개로 이 수수료도 백테스트 비용 계산에 반영
