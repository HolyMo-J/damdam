# 리뷰 항목 마무리

지금 세션에서 방금 끝낸 docs/review-tasks.md 항목 하나를 마무리한다. 순서대로 진행하고 중간에 임의로 건너뛰지 않는다.

1. **테스트 실행**
   - 이번 세션에서 수정한 파일을 기준으로 관련된 테스트를 찾아 돌린다 (예: 특정 서비스를 고쳤으면 해당 서비스 테스트, 범위가 불분명하면 `./gradlew test` 전체를 돌린다).
   - 실패하면 여기서 멈추고 사용자에게 실패 내용을 보여준다. 통과 여부를 사용자에게 알리기 전까지 다음 단계로 넘어가지 않는다.

2. **커밋 승인**
   - `git status`, `git diff`로 변경 내용을 확인하고 사용자에게 요약해서 보여준다.
   - 한글 커밋 메시지 초안을 제안한다.
   - 사용자가 승인하기 전까지 커밋하지 않는다. 승인 없이 커밋 명령을 실행하는 것은 금지된다.

3. **문서 갱신**
   - docs/review-tasks.md에서 방금 끝낸 항목 번호 뒤에 `[완료 YYYY-MM-DD]` 태그를 붙인다 (오늘 날짜 사용).
   - docs/todo.md와 docs/done.md를 짧게 덮어써서 갱신한다. 작업 일지처럼 쌓지 말고, 새 항목을 늘리지 않는다.
   - 이 문서 변경도 위 2번 커밋에 포함해 승인받는다 (또는 사용자가 원하면 별도 커밋으로 분리해도 된다).

4. **다음 안내**
   - docs/review-tasks.md에서 완료 표시가 없는 다음 항목 번호를 한 줄로 알려준다.
   - 이제 `/clear`를 입력하고 다음 세션을 시작하면 된다고 안내한다.
